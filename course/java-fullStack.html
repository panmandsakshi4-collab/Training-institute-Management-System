Subjects & Chapters

Learn each subject step-by-step throughout the 6-month program.

01

Core Java

Build strong fundamentals of Java programming.

Introduction to Java Features of Java JDK / JRE / JVM Variables Data Types Operators Input & Output Conditional Statements Loops Arrays Methods Strings Constructors Static Keyword Packages

Object-Oriented Programming

Understand the core OOP principles used in Java development.

Class & Object Constructor Encapsulation Inheritance Polymorphism Abstraction Interface Method Overloading Method Overriding
03

Advanced Java

Learn advanced programming concepts for application development.

Exception Handling Wrapper Classes StringBuilder File Handling Multithreading Generics Annotations Packages
04

Java Collections

Work with Java's powerful Collections Framework.

List Interface ArrayList LinkedList Vector Set Interface HashSet LinkedHashSet TreeSet Map Interface HashMap LinkedHashMap TreeMap Comparable Comparator

SQL & MySQL

Learn database concepts and write SQL queries.

DBMS RDBMS Tables Data Types Constraints DDL DML DCL TCL SELECT WHERE GROUP BY ORDER BY Joins Subqueries Functions Normalization
06

HTML

Learn the fundamentals of web page structure.

HTML Basics HTML Tags Attributes Headings Paragraphs Links Images Lists Tables Forms Input Elements Semantic HTML
07

CSS

Design modern and responsive web interfaces.

CSS Basics Selectors Colors Fonts Box Model Margin Padding Display Position Flexbox Grid Transitions Transform Responsive Design Media Queries
08

JavaScript

Add logic and interactivity to web applications.

Variables Data Types Operators Functions Arrays Objects Loops DOM Events Form Validation ES6 Basics
09

JDBC

Connect Java applications with databases.

JDBC Introduction JDBC Architecture Drivers Connection Statement PreparedStatement ResultSet CRUD Operations Database Connectivity
10

Servlet & JSP

Learn Java-based web application development.

Servlet Basics Servlet Lifecycle Request & Response Sessions Cookies JSP Basics Forms MVC Basics
11

Spring Framework

Understand the fundamentals of Spring Framework.

Spring Introduction IoC Dependency Injection Spring Beans Configuration Annotations
12

Spring Boot

Build modern backend applications and REST APIs.

Spring Boot Introduction Project Structure Maven REST API Controllers Services Repository CRUD API Exception Handling
13

Hibernate & JPA

Learn ORM and database integration with Java.

ORM Hibernate Architecture Entities Mapping JPA Repository CRUD Relationships
14

Development Tools

Learn tools commonly used in development workflows.

Eclipse IntelliJ IDEA VS Code Maven Git GitHub Postman
15

Project Development

Apply all technologies through practical project development.

Project Planning Requirement Analysis UI Development Database Design Backend Development REST API Testing GitHub Project Presentation
